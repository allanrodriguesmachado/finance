# Modelo Conceitual

## Usuário

Representa a pessoa que utiliza o sistema.

Relacionamentos:
- Um usuário possui várias receitas.
- Um usuário possui várias despesas.
- Um usuário possui vários investimentos.

## Receita

Representa dinheiro que entra.

Tipos:
- FIXA
- VARIÁVEL

Exemplos:
- Salário
- Freelance
- Comissão

## Despesa

Representa dinheiro gasto.

Tipos:
- AVULSA
- RECORRENTE
- PARCELADA

Exemplos:
- Lanche
- Internet
- Notebook parcelado

## Categoria

Classifica uma despesa.

Exemplos:
- Alimentação
- Casa
- Transporte
- Lazer
- Saúde

## Investimento

Representa dinheiro destinado à construção de patrimônio.

Exemplos:
- Tesouro Direto
- CDB
- Fundo
