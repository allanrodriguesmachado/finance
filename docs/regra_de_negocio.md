# Sistema de Gestão Financeira

## Objetivo
Permitir que uma pessoa controle sua renda, gastos,
parcelamentos, despesas recorrentes e planejamento mensal.

## Usuário
O sistema deve permitir cadastrar um usuário.

Regras:
- O usuário deve possuir nome.
- O usuário deve possuir e-mail.
- O e-mail não pode estar vazio.

## Receita
Uma receita representa dinheiro que entrou.

Exemplos:
- Salário: R$ 8.500
- Freelance: R$ 1.200
- Venda: R$ 500

Regras:
- O valor deve ser maior que zero.
- Deve possuir uma data.
- Pode ser fixa ou variável.

## Despesa
Uma despesa representa dinheiro que saiu.

Exemplos:
- Aluguel: R$ 1.500
- Gasolina: R$ 300
- Internet: R$ 139,90

Regras:
- O valor deve ser maior que zero.
- Deve possuir uma descrição.
- Deve possuir uma data.
- Pode ser única, recorrente ou parcelada.
